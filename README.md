## 如何理解配件

“无需外接模块”不等于“不需要任何其他东西”。例如 BTHome 使用内置蓝牙，但需要兼容的接收平台；MagicBand 灯光需要 MagicBand+ 手环。不同 ESP32、ESP8266、BW16、CC1101、nRF24 和相应固件不能随意互换。
