先看这里：配件、操作和资料范围

“无需外接模块”只表示不用给 Flipper 接 GPIO 扩展板；它仍可能需要一张相应的卡、遥控对象、手机、电脑或 Home Assistant。下方会分别标明，避免把“无需模块”误解成“什么都不用准备”。

常见操作是方向键选择、OK 进入、返回键退回；部分应用需要长按返回。各条目的步骤以作者文档或源码核对结果为准。资料不足的地方会标“待核对”，不猜针脚、供电或兼容型号。

这是一份使用参考，整理依据为 2026-10-30 已核验的目录、作者说明、官方应用目录和源码；文件已安装不等于全部功能都已实机测试。目录中的系统组件单列说明。干扰、凭据捕获和注入类工具列出用途、配件及观察/连接准备，不提供影响周边设备的自动化操作。

常见配件怎么区分
配件或接口对应用途与容易混淆的地方
ESP32 / ESP8266 / BW16不同芯片和不同板载固件对应不同应用。Marauder、FlipperHTTP、摄像头和调试固件不能仅凭“都是 ESP32”互换；BW16 也不是普通 ESP32。
CC1101外置 Sub-GHz 收发模块。Flipper 本身已有内置 Sub-GHz 收发器；是否必须外置，要看具体应用和使用模式。
nRF24L01 / PA+LNA2.4 GHz 收发模块，通常通过 SPI 使用；不能用 CC1101 代替。某些版本还需要独立、稳定的合适供电。
NFC / 125 kHz RFID / iButton是不同技术。许多读取功能使用 Flipper 内置接口，但目标卡种、钥匙类型或写入条件仍需要匹配。
I²C / SPI / UART / 1-Wire是连接协议，不是单一配件型号。准备应用明确支持的模块/芯片、对应连接线，并按模块与 Flipper 文档核对引脚和电平。
USB 数据线用于电脑通信、键盘/鼠标模拟、存储或调试；只有充电功能的线不能完成数据通信。
配套设备和服务例如 MagicBand+ 手环、Game Boy、兼容传感器、Home Assistant、手机 App 或电脑端服务。它们与 GPIO 扩展模块分开列出。

对于 ESP32/NRF24 与 CC1101/BW16/NRF24 组合板，仍需逐项核对芯片、接线及板载固件；有指示灯不代表所有这些应用都能直接通信。此手册不要求你购买全部配件。接口与电平参考 Flipper 官方硬件规格，具体板卡按对应作者文档核对。
